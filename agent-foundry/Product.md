# 个人量化操作系统 — 产品定义

版本：v2.0
日期：2026-05-31
状态：Agent Quant 架构重设计

---

## 一、产品愿景

一个 **Agent Quant** 系统——AI agent 是量化研究的"大脑"，负责扫描 5000 只 A 股、识别龙头、分析情绪、生成推荐；人类负责判断题材真伪、市场阶段、是否出手。

**一句话定义**：AI 帮你做 90% 的研究工作，你做 10% 的判断决策。

**核心模式**：Agent 推荐 → 人类决策 → Agent 从结果中学习 → 策略自我进化

---

## 二、Agent Quant vs 传统量化

| 维度 | 传统量化 | Agent Quant（本系统） |
|------|----------|---------------------|
| 信号生成 | 数学模型、因子模型 | LLM 推理多源数据 |
| 数据源 | 结构化（OHLCV、基本面） | 结构化 + 非结构化（新闻、龙虎榜、社交媒体） |
| 策略进化 | 参数优化、回测 | 反思式自我修正、记忆 |
| 人类角色 | 设计策略、编码、部署 | 判断 agent 推荐、决定市场阶段 |
| 市场理解 | 统计模式 | 叙事理解（题材、辨识度、情绪周期） |
| 适应性 | 定期重训模型 | 每笔交易实时学习 |
| 适合场景 | 高频、统计套利 | 题材驱动、龙头选股、情绪择时 |

---

## 三、目标用户

- **个人投资者**：想用量化方法做"退学炒股"风格的短线交易
- **AI 原生用户**：依赖 AI 做研究，自己做决策

## 四、系统架构

### 四层 Agent 架构（参考 TradingAgents）

```
┌─────────────────────────────────────────────────────┐
│  第一层：扫描层（并行，快速模型）                       │
│  ├── 技术扫描 Agent（量价异动、MACD、RSI）             │
│  ├── 情绪扫描 Agent（新闻、龙虎榜、社交媒体）           │
│  ├── 涨停池 Agent（连板高度、炸板率、首板溢价）         │
│  └── 板块轮动 Agent（资金流向、板块强度）               │
├─────────────────────────────────────────────────────┤
│  第二层：分析层（深度模型）                            │
│  ├── 龙头识别 Agent（龙头/跟风/补涨 评分）             │
│  ├── 情绪周期 Agent（冰点→修复→发酵→高潮→退潮）       │
│  └── 多空辩论 Agent（看多 vs 看空，2 轮辩论）          │
├─────────────────────────────────────────────────────┤
│  第三层：决策层（人类 + Agent 协作）                    │
│  ├── 报告生成 Agent → 结构化推荐报告                   │
│  ├── 人类判断：题材真伪、市场阶段、是否出手             │
│  └── 决策记录 → 写入记忆系统                           │
├─────────────────────────────────────────────────────┤
│  第四层：学习层（持续进化）                             │
│  ├── 交易结果追踪                                      │
│  ├── 反思生成（LLM 分析对错原因）                      │
│  ├── 策略版本管理                                      │
│  └── 记忆注入下次分析                                   │
└─────────────────────────────────────────────────────┘
```

### 分工边界

| 谁负责 | 做什么 | 不做什么 |
|--------|--------|----------|
| **机器/AI** | 扫描 5000 股、算指标、找龙头、分析龙虎榜、读新闻、生成报告 | 不做最终交易决策 |
| **人类** | 判断题材真假、判断市场阶段、决定是否出手、评估风险承受 | 不做数据收集和指标计算 |

### 输入输出

**输入**（机器自动采集）：
- 日线/5min K 线数据（Baostock）
- 涨停池/炸板池/跌停池（AKShare）
- 龙虎榜（AKShare）
- 板块资金流（AKShare）
- 北向资金（AKShare）
- 新闻/公告（WebFetch）
- 社交媒体热度（AKShare）

**输出**（Agent 生成，人类审阅）：
- 每日推荐报告（Top 10 候选股，含评分、题材、阶段、止损）
- 情绪温度报告（当前市场周期、转换信号）
- 龙头追踪报告（连板高度、龙头更替）
- 风险预警（异常信号、退潮预警）

## 五、Agent 定义

### 5.1 scanner-agent（扫描 Agent）

```yaml
职责: 扫描全 A 股，筛选候选股
模型: DeepSeek v4-flash（快速、便宜）
输入: 全量日线数据、涨停池
输出: Top 50 候选股 + 技术评分
触发: 每日收盘后自动运行
```

### 5.2 sentiment-agent（情绪 Agent）

```yaml
职责: 分析新闻、龙虎榜、社交媒体情绪
模型: DeepSeek v4-flash / Qwen（中文理解）
输入: 候选股列表 + 新闻/龙虎榜数据
输出: 每只股票的情绪评分（1-10）+ 关键因素
触发: 每日收盘后、重大新闻时
```

### 5.3 leader-agent（龙头 Agent）

```yaml
职责: 识别龙头股，判断市场阶段
模型: DeepSeek v4-pro / Claude（深度推理）
输入: 候选股 + 情绪分析 + 涨停池数据
输出: 龙头/跟风/补涨 分类 + 市场阶段判断
触发: 每日收盘后
```

### 5.4 debate-agent（辩论 Agent）

```yaml
职责: 多空辩论，找推荐的漏洞
模型: DeepSeek v4-pro（深度推理）
输入: 龙头推荐 + 所有分析数据
输出: 看多/看空论点 + 辩论结论
触发: 每次推荐前
```

### 5.5 report-agent（报告 Agent）

```yaml
职责: 汇总所有分析，生成人类可读报告
模型: DeepSeek v4-flash
输入: 扫描结果 + 情绪分析 + 龙头识别 + 辩论结论 + 历史记忆
输出: 结构化推荐报告
触发: 每日收盘后
```

### 5.6 reflect-agent（反思 Agent）

```yaml
职责: 交易结束后分析对错，更新策略
模型: DeepSeek v4-pro
输入: 原始推荐 + 实际结果
输出: 反思笔记 + 策略调整建议
触发: 交易结束后 T+1 或 T+2
```

## 六、记忆系统

### 记忆架构

```
memory/
├── MEMORY.md                    # 索引（每次会话加载）
├── trade_history.jsonl          # 每笔交易记录（推荐理由 + 结果）
├── lessons_learned.md           # LLM 生成的反思笔记
├── strategy_current.md          # 当前策略定义（版本化）
├── strategy_changelog.md        # 策略变更日志
├── sector_momentum.md           # 板块动量追踪
├── dragon_tiger_notes.md        # 龙虎榜观察笔记
└── sentiment_archive.md         # 情绪历史 + 结果对照
```

### 反思循环

```
推荐 → 人类决策 → 交易执行 → 结果揭晓
                                      ↓
                               反思 Agent 分析
                                      ↓
                            ┌─────────────────────┐
                            │ 对了什么？错了什么？   │
                            │ 哪个信号该加权？       │
                            │ 市场阶段判断准吗？     │
                            │ 下次该注意什么？       │
                            └─────────────────────┘
                                      ↓
                              写入 lessons_learned.md
                                      ↓
                            下次分析时注入 Agent 上下文
```

### 策略版本管理

```
strategy_v1.md  → 初始退学炒股规则
strategy_v2.md  → 第一个月调整（加入的教训）
strategy_v3.md  → 当前版本
changelog.md    → 每次变更的记录和原因
```

## 八、LLM 集成

### 多模型策略

| 用途 | 推荐模型 | 原因 |
|------|----------|------|
| 批量扫描（5000 股筛选） | DeepSeek v4-flash | 最便宜，2500 rpm |
| 情绪分析（新闻/龙虎榜） | DeepSeek v4-flash / Qwen | 中文理解好 |
| 龙头识别（深度推理） | DeepSeek v4-pro | 需要复杂推理 |
| 多空辩论 | DeepSeek v4-pro | 需要深度思考 |
| 反思生成 | DeepSeek v4-pro | 需要分析能力 |
| 报告生成 | DeepSeek v4-flash | 格式化任务 |

### 接入方式

用户自行提供 API Key，通过环境变量配置：
```
DEEPSEEK_API_KEY=xxx
DASHSCOPE_API_KEY=xxx    # Qwen
ANTHROPIC_API_KEY=xxx    # Claude（可选）
```

系统通过 LiteLLM 统一调用，自动 fallback。

## 九、与 S1-S7 的关系

S1-S7（回测引擎）**保留不变**，作为 Agent Quant 的基础设施：

| S1-S7 模块 | 在 Agent Quant 中的角色 |
|------------|----------------------|
| S1 数据层 | 为 Agent 提供结构化数据 |
| S2 表达式引擎 | Agent 计算技术指标的工具 |
| S3 回测引擎 | Agent 验证策略的沙盒 |
| S4 策略层 | Agent 生成策略代码的框架 |
| S5 A 股规则 | Agent 必须遵守的约束 |
| S6 模拟实盘 | Agent 纸上交易验证 |
| S7 可视化 | 展示 Agent 分析结果 |

**新增模块**：

| 模块 | 说明 |
|------|------|
| S8 情绪数据采集 | 涨停池/炸板池/龙虎榜/板块资金流 |
| S9 Agent 框架 | 多 Agent 编排、记忆系统、反思循环 |
| S10 退学炒股策略 | 龙头识别 + 情绪周期 + 打板策略 |
| S11 报告系统 | 每日推荐报告 + 可视化 |
| S12 策略进化 | 反思循环 + 策略版本管理 |

## 十、非目标（v2.0 明确不做）

| 不做 | 理由 |
|------|------|
| 实盘自动交易 | Agent 推荐，人类决策 |
| 高频/Tick 级 | 退学炒股是日线级别策略 |
| 多市场（美股/港股） | 先聚焦 A 股 |
| 完全自主决策 | 人类判断不可替代（题材真伪） |
| LLM 实时盘中决策 | LLM 用于盘后分析，盘中用规则引擎 |

## 十一、成功标准

### 验收故事 1：每日扫描
```
Given 收盘后运行 agent 扫描
When  扫描完成
Then  输出 Top 50 候选股
And   每只股有技术评分、情绪评分、龙头评分
And   运行时间 < 10 分钟
```

### 验收故事 2：龙头识别
```
Given 涨停池数据 + 连板数据
When  leader-agent 分析
Then  输出龙头/跟风/补涨分类
And   给出市场阶段判断（冰点/修复/发酵/高潮/退潮）
And   判断有依据（连板高度、炸板率、封板时间等）
```

### 验收故事 3：推荐报告
```
Given 所有 Agent 分析完成
When  report-agent 生成报告
Then  输出结构化推荐（Top 10）
And   每只股有：代码、名称、题材、地位、阶段、止损、信心度
And   包含风险提示和核心逻辑
```

### 验收故事 4：反思循环
```
Given 一笔交易完成（T+2）
When  reflect-agent 分析
Then  对比推荐 vs 实际结果
And   生成反思笔记（对了什么、错了什么、下次注意什么）
And   写入 lessons_learned.md
And   下次分析时 Agent 能引用这些教训
```

### 验收故事 5：策略进化
```
Given 累计 10 笔交易
When  查看 strategy_changelog.md
Then  可以看到策略从 v1 到当前版本的变化
And   每次变更有原因说明
And   当前策略反映了历史教训
```
