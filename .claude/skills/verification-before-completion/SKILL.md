# verification-before-completion

## 触发条件

- 准备说完成、修好了、测试通过、可以提交或可以上线。
- 准备结束当前会话。
- 准备让用户评审结果。

## 新鲜验证证据

必须在本轮完成前运行能证明结论的命令。旧输出、主观判断和“应该可以”都不算。

## 验证选择

- 代码变更：运行相关测试，必要时全量测试。
- 生成器变更：运行生成命令，并检查生成文件。
- 文档模板变更：检查目标文件内容和中文输出。
- bug 修复：运行原始复现命令和回归测试。

## 记录要求

- 记录命令和结果。
- 记录失败数、通过数或 exit code。
- 如果无法运行，说明原因和剩余风险。
- 把关键验证证据写入 Progress.md、WorkingContext.md 或 FinishGate.md。

## 输出要求

返回验证命令、验证结果、覆盖范围、未验证范围和下一步。
