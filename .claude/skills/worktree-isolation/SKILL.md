# worktree-isolation

## 触发条件

- 当前工作区有未提交变更。
- 要执行风险较高或较长的功能开发。
- 多个 agent 或多个切片可能并行修改代码。

## 隔离策略

- 优先确认当前 git 状态。
- 小型单线任务可在当前分支执行，但必须记录状态。
- 长任务、并行任务或实验性任务使用独立分支或 worktree。
- 不移动、删除或覆盖用户未确认的变更。

## 工作区记录

Progress.md 或 WorkingContext.md 记录：

- 当前分支。
- worktree 路径。
- 任务范围。
- 与主工作区的合并方式。
- 清理或保留决策。

## 完成处理

完成后进入 finish-gate，决定提交、合并、保留、推送或清理。

## 输出要求

返回 git 状态、隔离方式、分支或 worktree 信息、风险和下一步。
