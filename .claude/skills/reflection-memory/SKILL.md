# reflection-memory

## 触发条件

- 任一阶段完成或被阻塞。
- 发现重复问题、有效流程、工具限制或用户明确偏好。
- 新会话需要更容易恢复上下文。

## 阶段复盘

复盘不是项目结束才做。每个阶段结束都要记录：

- 本阶段做了什么。
- 哪些做法有效。
- 哪些问题拖慢或返工。
- 下次应提前检查什么。
- 哪些内容应进入长期记忆。

## 记忆分层

| 文件 | 写入内容 |
|---|---|
| Reflection.md | 阶段经验、复盘条目 |
| Memory.md | 长期稳定规则、项目偏好、可复用模式 |
| Feedback.md | 重复问题、需要形成约束的反馈 |
| WorkingContext.md | 下次继续工作必须知道的当前状态 |

## 过滤规则

- 只写可复用经验，不写聊天流水账。
- 不确定是否长期有效的先放 Reflection.md。
- 影响后续执行纪律的写入 Feedback.md 或 Memory.md。

## 输出要求

更新 Reflection.md、Memory.md、Feedback.md 或 WorkingContext.md；返回沉淀条目、证据来源和后续影响。
