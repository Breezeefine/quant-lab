# parallel-dispatch

## 触发条件

- 有多个互不依赖任务，可以同时调研、审查或验证。
- 任务共享上下文很少，合并结果成本低。
- 串行执行会明显拖慢进度。

## 并行前检查

- 每个任务有独立输入、输出和完成标准。
- 不会同时修改同一文件或同一状态文档。
- 结果可以由主 agent 汇总，不需要子 agent 互相沟通。

## 分派格式

每个并行任务都写清：

- 任务目标。
- 必读上下文。
- 禁止修改范围。
- 预期输出格式。
- 验证方式。

## 汇总门禁

- 不直接相信子 agent 的完成声明。
- 逐项检查证据和文件 diff。
- 冲突结论要回到资料或代码验证。
- 汇总后更新 Research.md、Progress.md、Review 文档或 WorkingContext.md。

## 输出要求

返回并行任务列表、每个任务结论、冲突处理、采纳内容、未采纳内容和下一步。
